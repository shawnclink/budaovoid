# Archive · 原始文本（脱敏公开版）

这里是从私人对话归档中整理出的原始文本，作为网站文章和项目的底稿保留。它不是网站的一部分：站点只构建 `src/` 和 `public/`，`archive/` 不会进入任何页面。

## 包含

- `raw-dialogues/`：五篇整理后的核心对话（宿命论、禅意八问、白夜行、弱自由意志、系统工程化人生）。
- `monologues/`：六篇戏剧化中文底稿，作为网站英文 Dramatic edition 的翻译底本；标题与真实时间线保留，场景为想象。它们不在网站正文中直接展示。
- 网站上的脱敏中文原文在 `src/content/originals/`；英文戏剧版在 `src/content/stories/`。
- `transcripts/`：三篇 DeepSeek 原始导出，以及 `文本.txt`。
- `telegram/hedwig-2026-07-03.txt`：发给自己的安那其主义与互助论备忘录。
- `vision/`：《项目愿景与未来展望》原始文档。
- `README-original.md`：原归档说明（已把个人称呼改为 buDaoVoid）。

## 未包含

- Telegram `inbox/` 的 35 条私人消息快照：里面是训练计划、身体数据、链接和日常记录，不属于哲学原文。
- `extracted/`：由 AI 扫描生成的摘录索引，不是原始文本。
- 个人画像、家庭、学校、城市、身心健康等个人信息。

## 日期

文件名和正文里的日期保留原样。文章页上的日期来自这些原始记录，不做统一改写。

## 说明

少量与身体、家庭、位置相关的词已做脱敏替换；哲学讨论中的“家庭”“创伤”“药物”等抽象用法保留。`raw-dialogues/` 是逐字转录；`monologues/` 是在此基础上的剧场化重写，不是逐字副本。原文中的 AI 回复也保留在 `raw-dialogues/` 里，便于看出哪些论点是在对话中推出来的。
